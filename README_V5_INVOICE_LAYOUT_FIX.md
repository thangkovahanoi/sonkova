# V5 Invoice Layout Fix

Hóa đơn nhiệt 80mm đã được bố trí lại theo dạng bảng từ trái sang phải:

**TÊN HÀNG | SL | ĐƠN GIÁ | THÀNH TIỀN**

- Tên hàng nằm ở cột trái và tự xuống dòng.
- SKU (nếu bật) nằm dưới tên hàng.
- Số lượng ở cột SL.
- Đơn giá ở cột ĐƠN GIÁ.
- Thành tiền ở cột cuối, căn phải.
- Mẫu xem trước trong Admin được cập nhật theo cùng bố cục.
