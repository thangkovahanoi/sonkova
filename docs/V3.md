# V3 feature map

## POS
- Tìm sản phẩm
- Quét barcode
- Thêm vào giỏ
- Tăng/giảm số lượng
- Giảm giá
- Chọn phương thức thanh toán
- Tạo số hóa đơn
- Lưu `sales` + `sale_items`
- Trừ tồn bằng transaction
- Gửi hóa đơn sang Xprinter

## Multi warehouse
- `warehouses`
- `warehouse_stock`
- Chuyển kho database-ready
- Kho làm việc được chọn ở sidebar

## CRM
- `customers`
- `suppliers`
- Công nợ là field sẵn sàng cho bước thanh toán/công nợ nâng cao

## Reports
- Tồn kho
- Giá trị tồn
- Hàng sắp hết
- View doanh thu theo ngày
- View sản phẩm bán chạy

## Production hardening cần làm trước khi triển khai thật
- Role/permission (admin, manager, cashier, warehouse)
- Audit log
- API key/HTTPS cho Print Bridge
- Transaction đầy đủ cho tạo đơn + trừ kho (hiện UI đã gọi transaction cho stock movement; production nên gom sale + stock vào một RPC)
- Sao lưu database
- Chuẩn hóa encoding tiếng Việt trên ESC/POS theo đúng firmware/font của N160I
- Tích hợp Xprinter iOS SDK thật
