# KHO XPRINTER V2

## Đã nâng cấp

1. Đăng nhập/đăng ký Supabase Auth.
2. RLS cho products, stock_movements, print_jobs.
3. RPC `apply_stock_movement()` cập nhật tồn kho atomic, tránh race condition.
4. Quét barcode bằng camera với ZXing.
5. Tìm sản phẩm theo SKU/barcode.
6. Modal chi tiết sản phẩm.
7. In tem sản phẩm.
8. Trang quản lý máy in + kiểm tra Windows Print Bridge.
9. Responsive tốt hơn cho iPhone.
10. Kiến trúc sẵn cho Bluetooth iPhone và LAN/USB Windows.
11. Print job table cho bước audit/queue tiếp theo.

## Chạy web

```bash
cd web
npm install
cp .env.example .env.local
npm run dev
```

## Supabase

Chạy `supabase/schema.sql` trong SQL Editor.

Nếu project đã chạy V1, hãy chạy file này sau khi backup database; các bảng hiện có sẽ được giữ lại và các cột/tables mới sẽ được bổ sung.

## Barcode

Camera yêu cầu HTTPS trong môi trường production (localhost được browser cho phép). Trên iPhone, website production nên chạy HTTPS.

## Xprinter

Windows:
`Web -> LAN -> Print Bridge -> USB -> N160I`

iPhone:
`Web -> iOS companion/SDK -> Bluetooth -> N160I`

V2 không giả lập Bluetooth. Adapter iOS cần gắn SDK của Xprinter để giao tiếp đúng với phần cứng.
